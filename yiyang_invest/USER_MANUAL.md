## 一、平台概览

### 1.1 平台定位

益阳高新区智慧招商平台是面向 **链主企业 → 上游供应商 → 下游应用商** 三方共赢的产业招商工具。核心目标：

- **链主企业**：发布采购需求、开放技术能力、悬赏技术难题
- **上游供应商**：浏览采购机会、在线响应、注册入驻供应商池
- **下游应用商**：查看链主开放的技术资源，寻找合作机会
- **招商团队**：管理线索、跟进项目、撮合供需对接

### 1.2 四大赛道

| 赛道 | 代表企业 | 招商方向 |
|------|---------|---------|
| 智能感知 | 麓宇光电 | 光电传感器、激光雷达模组 |
| 工业视觉 | 信维电科、金博股份 | AI视觉检测、AOI设备 |
| 装备智能 | 三一重工、益阳橡机 | 智能控制器、工业软件 |
| 算力配套 | 益阳智算中心 | GPU算力、数据中心配套 |

### 1.3 技术架构

- 后端：Python Flask + SQLAlchemy
- 前端：HTML/CSS/JS（纯原生，无框架依赖）
- 数据库：SQLite（开发）/ PostgreSQL（生产）
- 外部集成：天眼查 CLI（企业查询、招投标同步）

### 1.4 访问地址

| 环境 | 地址 |
|------|------|
| 本地开发 | `http://localhost:5096` |
| 后台登录 | `http://localhost:5096/auth/login` |

## 三、前台页面（访客视角）

### 3.1 首页 `/`

- **供需看板**：展示实时数据（采购需求数、供应商数、响应次数、项目数、采购总额）
- **热力图**：长株潭区域企业密度可视化
- **四大赛道**：智能感知 / 工业视觉 / 装备智能 / 算力配套
- **核心优势**：6 大优势卡片
- **新闻动态**：4 条最新新闻，点击标题可跳转官方原文

### 3.2 产业生态 `/industry`

- ECharts 力导向图展示产业链上下游关系
- 绿色节点 = 已有基础，橙色虚线 = 薄弱环节，红色虚线 = 招商空白
- 按赛道Tab筛选，每个节点展示详情和缺口等级

### 3.3 供应商专区 `/supplier-zone`

- 6 家链主企业卡片
- **采购需求发布板**：8 条实时需求，可按状态/赛道/类型筛选
- **供应链成本计算器**：选择当前城市 + 输入月运输量，自动估算搬迁后年物流成本节省额

### 3.4 供应商池 `/suppliers`

- 5 家已注册供应商企业列表
- 可按赛道/规模筛选，支持关键词搜索（企业名/产品/标签）
- 点击进入企业详情页，查看资质、产品、匹配的采购需求
- "注册入驻"按钮可自助入驻

### 3.5 技术悬赏板 `/tech-challenges`

- 3 条链主企业发布的技术难题悬赏
- 按赛道/类型筛选
- 产学研合作通道展示合作高校/机构

### 3.6 下游专区 `/downstream-zone`

- 5 项链主企业对外开放的技术能力
- 类型：算力服务 / 产线测试 / 技术合作 / 产品供应 / 联合研发

### 3.7 其他页面

| 页面 | 地址 | 说明 |
|------|------|------|
| 空间载体 | `/space` | 孵化区/制造区空间详情、园区实景图 |
| 政策服务 | `/policy` | 税收/人才/租金/科创/金融 5 类政策 |
| 在线对接 | `/contact` | 招商意向表单（提交后自动生成线索） |
| 供应商入驻 | `/supplier-register` | 企业自助注册（需填写能力信息） |
| 需求详情 | `/supplier-zone/demand/<id>` | 需求完整信息 + "我要响应"按钮 |
| 企业详情 | `/supplier/<id>` | 供应商能力展示 + 匹配需求 + 同赛道链主 |

## 四、后台管理（招商团队视角）

### 4.1 数据驾驶舱 `/admin`

- **4 个 KPI 卡片**：线索数、洽谈中项目、签约金额、可用空间
- **项目阶段漏斗图**：线索 → 洽谈 → 签约 → 落地 → 投产
- **线索来源饼图**：展会/推介会/以商招商/网络线索/在线表单
- **赛道分布柱状图**
- **近期跟进动态**：时间线展示

### 4.2 线索池 `/admin/leads`

- 线索列表，按状态筛选（待处理/对接中/已转化/已关闭）
- 新增线索：填写企业名/联系人/赛道/来源/意向程度，分配给负责人
- **线索转项目**：点击"转化"，自动生成企业+项目，更新线索状态

### 4.3 项目管理 `/admin/projects`

- **看板视图**：5 列（线索/洽谈/签约/落地/投产），卡片拖拽感受
- **列表视图**：表格展示，按阶段/赛道筛选
- 新增/编辑项目，添加跟进记录（支持历史记录展示）

### 4.4 客商库 `/admin/companies`

- **双视图**：表格视图 + 地图视图（含热力图）
- 企业类型：入驻企业 / 目标客商 / 供应商
- **天眼查导入**：在线搜索企业 → 一键导入客商库
- 支持坐标填充、招投标同步

### 4.5 采购需求管理 `/admin/demands`

- 8 条采购需求列表，按赛道/类型筛选
- 新增/编辑/删除需求（选择链主企业、填写金额/品类/资质要求等）
- 每条需求可查看供应商响应列表

### 4.6 响应管理 `/admin/responses`

- **汇总视图**：所有供应商对采购需求的响应
- 按状态筛选：待审核 / 审核中 / 已通过 / 已拒绝
- 一键操作：标记审核中、通过、拒绝
- 点击查看详情（资质、优势描述）

### 4.7 技术能力管理 `/admin/tech-capabilities`

- 链主企业对下游开放的技术能力列表
- 新增/编辑/删除

### 4.8 技术悬赏管理 `/admin/tech-challenges`

- 3 条技术悬赏列表
- 新增/编辑/删除，支持设置悬赏金额和截止日期

### 4.9 资源管理页面

| 页面 | 说明 |
|------|------|
| `/admin/spaces` | 空间管理：孵化区/制造区，切换状态（可租/已预订/已入驻） |
| `/admin/policies` | 政策管理：新增/编辑/删除招商政策 |
| `/admin/articles` | 内容管理：新增/编辑新闻，支持封面图拖拽上传、填写原文链接 |
| `/admin/park-images` | 园区实景：多图上传、分类、排序、删除 |
| `/admin/users` | 用户管理（仅管理员）：新增/编辑用户，分配角色 |

## 五、核心工作流程

### 5.1 招商全流程：线索 → 项目 → 落地

```
在线表单/展会/推介会 → 线索池
     │
     ▼
待处理 → 对接中（电话/视频会议）
     │         │
     │         ▼
     │      已转化（生成项目+企业）
     │         │
     │         ▼
     │      洽谈 → 签约 → 落地 → 投产
     │         │
     │         ▼
     │      跟进记录（每次沟通记录）
     │
     ▼
  已关闭（暂时放弃，可重新激活）
```

**操作步骤**：
1. 进入线索池 → 点击"新增线索"
2. 联系企业 → 更新线索状态为"对接中"
3. 确认意向后 → 点击"转化" → 填写项目名/投资额 → 自动生成项目
4. 进入项目管理 → 更新项目阶段
5. 每次沟通后在项目下添加跟进记录

### 5.2 供需撮合流程：链主 ← → 供应商

```
链主发布采购需求 → 供应商专区展示
                       │
                       ▼
              供应商浏览需求
                       │
                       ▼
           点击"我要响应"填写信息
                       │
                       ▼
          后台响应管理审核（通过/拒绝）
                       │
                       ▼
           审核通过 → 转线索 → 转项目
```

### 5.3 技术攻关流程：链主 ← → 高校/企业

```
链主发布技术悬赏 → 技术悬赏板展示
                       │
                       ▼
              高校/企业查看悬赏
                       │
                       ▼
              在线提交揭榜意向
                       │
                       ▼
              招商团队对接撮合
```

### 5.4 供应商自助入驻

```
供应商访问 /supplier-register
     │
     ▼
填写企业信息+能力展示+资质证书
     │
     ▼
提交 → 自动加入供应商池
     │
     ▼
链主可在供应商池中搜索到该企业
```

## 六、数据字段说明

### 6.1 线索（Lead）

| 字段 | 说明 | 必填 |
|------|------|:--:|
| 企业名称 | 目标企业全称 | ✅ |
| 联系人/电话 | 企业对接人 | |
| 来源 | 展会/推介会/以商招商/网络线索/在线表单 | |
| 意向赛道 | 四大赛道之一 | |
| 意向程度 | 高/中/低 | |
| 状态 | 待处理→对接中→已转化→已关闭 | |
| 负责人 | 分配给哪位招商人员 | |

### 6.2 项目（Project）

| 字段 | 说明 |
|------|------|
| 项目名称 | 如："XX公司AI视觉检测装备华中基地" |
| 关联企业 | 可选，关联客商库企业 |
| 阶段 | 线索→洽谈→签约→落地→投产 |
| 投资金额 | 万元 |
| 赛道 | 四大赛道之一 |
| 预计落地日期 | 计划落地时间 |
| 实际落地日期 | 签约/落地后填写 |

### 6.3 采购需求（ProcurementDemand）

| 字段 | 说明 |
|------|------|
| 发布企业 | 链主企业 |
| 类型 | 年度采购/紧急采购/供应商招募 |
| 品类 | 原材料/零部件/设备/软件/服务 |
| 预估金额 | 如"2000万元/年" |
| 资质要求 | 对供应商的硬性要求 |
| 截止日期 | 报名截止时间 |
| 状态 | 招募中/已截止 |

### 6.4 供应商响应（DemandResponse）

| 状态 | 含义 |
|------|------|
| `pending` | 待审核（供应商刚提交） |
| `reviewing` | 审核中（招商专员已查看） |
| `approved` | 已通过（可进入线索转化） |
| `rejected` | 已拒绝 |

## 七、常见问题

**Q1: 在线表单提交后会怎样？**
A: 自动在后台生成一条"待处理"状态的线索，招商专员可在线索池中看到并分配。

**Q2: 线索转为项目后，线索还在吗？**
A: 线索状态变为"已转化"，线索仍保留在系统中，关联字段 `converted_project_id` 指向生成的项目。

**Q3: 采购需求发布后供应商怎么知道？**
A: 供应商通过对外公开的"供应商专区"页面浏览，无需登录。看到合适的可在线提交响应。

**Q4: 供应商响应后怎么处理？**
A: 进入后台"响应管理"页面，查看详情 → 标记审核中 → 审核通过后转入线索池。

**Q5: 链主企业怎么增加？**
A: 后台"客商库"中新增企业，勾选"链主企业"标识即可。

**Q6: 热力图没数据怎么办？**
A: 企业需有经纬度坐标。在客商库中点击"填充坐标"按钮（需天眼查 CLI 配置），或手动填写。

**Q7: 怎么备份数据？**
A: 开发环境直接复制 `yiyang_invest.db` 文件。生产环境使用 `deploy/backup.sh` 脚本。

**Q8: 忘记密码怎么办？**
A: 联系管理员重置。管理员在 `/admin/users` 可修改任何用户密码。
